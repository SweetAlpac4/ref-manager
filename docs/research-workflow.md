# Collect, read, and organize references

[Back to README](../README.md)

## Build a reading list

1. In **Search**, enter a DOI for a specific work or use **Title** to find a likely match. Check the title, authors, and year before saving.
2. For a list of mixed DOIs and titles, choose **Batch** and paste one item per line, up to 50. Review the matches and use **Save all to library** to save the found references, or open individual results first.
3. For an item that cannot be found online, use **Library → Add reference**. Enter the title and any fields you need for citations. For personal names, use one author per line in `Last name, First name` format. Enter an organization name on its own line.

## Keep the library manageable

Open a reference to edit its metadata or set collections, tags, and reading status. Enter collections and tags as comma-separated lists, then choose **Save settings**. For example, use a collection to group a literature review and tags to track topics across several projects.

In **Library**, combine a search with filters. Choose **Without local PDF** and a collection to find entries that still need an attachment. Use **Recently added (30 days)** with the **Unread** status to build a reading queue. The selection controls let you export or remove several records at once.

Use **Find duplicates** to review potential matches and select the record to keep. Merging fills missing fields, combines collections and tags, relinks notes, and moves attachments to the kept record. Check the proposed pair first, especially when a paper and its preprint have similar titles.

## Read and find passages in PDFs

1. Open a reference and use **Attach PDF**, then **Read PDF**.
2. In the reader, search for a phrase, navigate to a page, and adjust the zoom. In the library, **Search PDF contents** looks across local attachments and **Open page** jumps to a match.
3. Select text and choose **Highlight selected text**. Add a comment if needed and save the annotation. Use **Add sticky note** to comment on a page without selecting text.
4. Choose **Copy to notes** under an annotation to create a linked excerpt or note. Downloading the PDF gives you the original file. Use a [workspace backup](data-and-backups.md) to move both the file and its annotations.

[Search PDF contents showing a matching page and a button to open it](screenshots/pdf-search.png)

If a PDF has no selectable text, the reader can still display its pages. You can add page notes, but search and text highlighting require a text layer. For embedded title, author, or DOI, choose **Read PDF metadata** and apply only the suggested fields you want.

## Turn reading notes into a draft

Open **Library → Research notes** to search your notes and excerpts. Create a **Research insight** for a conclusion that draws on more than one source, then select those sources in **Related references**. Create a standalone note by leaving that field empty. For notes tied to one work, open the reference and use **Reference notes**.

[Research Notes showing an excerpt copied from an annotated PDF and linked to its source](screenshots/research-notes.png)

When you are ready to write, open the [Citation workspace](citation-workflow.md).
